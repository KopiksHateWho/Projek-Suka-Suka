## 2024-05-15 - [Accessible Password Toggles]
**Learning:** Password visibility toggle buttons using absolute positioning (e.g., `right-4`) require additional horizontal padding (e.g., `pr-12`) on the input field to prevent text overlap when long passwords are typed. For accessibility, icons should switch between standard emojis (🙈/👁️) and update `aria-label` and `title` attributes accordingly.
**Action:** Always wrap password inputs in a `relative` container and ensure the input has enough `padding-right` to accommodate the toggle button. Use English for all `aria-label` attributes to maintain consistency in global design systems.
